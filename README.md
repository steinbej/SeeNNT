# SeeNNT

**[Open SeeNNT](SeeNNT.html)**

SeeNNT is a teaching tool that shows two treatments side by side as icon arrays, with one icon per person. It helps learners see what a difference in outcome rates means: how many people per 100 (or per 1,000) have a different outcome, and how that becomes a number needed to treat (NNT) or number needed to harm (NNH).

Features:
- 100- or 1,000-person grids
- Rates entered as percentages, as events / patients, or as baseline risk plus a relative effect
- The extra outcomes in the better arm are highlighted in their own color
- Optional side-effect rings
- A switch that counts the outcome or its opposite, to show how framing changes the relative figure but not the absolute one
- Colorblind-friendly color schemes
- Editable labels
- Full-screen presentation mode, plus PNG, SVG and PDF export

It is a single HTML file with no installation and no data collection. To use it offline, download `SeeNNT.html` and open it in any browser.

Feedback is welcome through the **Issues** tab.
